# История изменений

## 0.1.0

Первая версия

- загрузка PDF, DOCX, Markdown и TXT с сохранением страниц и разделов, в том числе TXT в кодировке Windows-1251
- нарезка на фрагменты по абзацам и предложениям с перекрытием
- лексический поиск BM25 с русским стеммингом, векторный поиск и их слияние методом RRF
- не больше двух фрагментов из одного документа в выдаче, чтобы у вопросов-сравнений были источники по обеим темам
- инкрементальная индексация по SHA-256, работающий сервер видит изменения индекса без перезапуска
- ответы через Ollama со ссылками на фрагменты и потоковой выдачей
- обработка моделей с рассуждениями: отключение у гибридных Qwen3, скрытие блока рассуждений у остальных
- оценка поиска по Hit@k, Recall@k, MRR и nDCG, генерация набора вопросов моделью
- корпус для оценки из 54 статей Википедии со скриптом загрузки и 51 вопросом, написанным вручную
- командная строка, HTTP API и веб-интерфейс со светлой и тёмной темой
