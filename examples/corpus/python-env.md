# Окружение Python для аналитических проектов

## Виртуальные окружения

Каждый проект живёт в собственном виртуальном окружении, чтобы версии библиотек разных проектов не конфликтовали. Окружение создаётся командой python -m venv .venv в корне проекта. В Windows оно активируется скриптом .venv\Scripts\activate, в Linux и macOS командой source .venv/bin/activate.

Папку .venv никогда не добавляют в репозиторий: её вносят в .gitignore.

## Зависимости

Список зависимостей фиксируется в файле pyproject.toml или requirements.txt. Для воспроизводимости версии закрепляют точно, например pandas==2.2.2. Обновление зависимостей делается отдельным pull request, чтобы при поломке было легко найти причину.

## Jupyter

Ноутбуки удобны для исследования, но не для промышленного кода. Повторяющаяся логика выносится в модули внутри пакета проекта, а ноутбук только вызывает функции. Перед коммитом из ноутбуков очищают вывод ячеек, иначе в истории оседают мегабайты картинок и возможные персональные данные.

## Форматирование и проверки

Код форматируется автоматически инструментом ruff format, а линтер ruff check запускается перед каждым коммитом через pre-commit. Тесты пишутся на pytest и лежат в папке tests.
