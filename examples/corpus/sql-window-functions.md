# Оконные функции в SQL

## Зачем они нужны

Оконная функция считает значение по набору строк, связанных с текущей строкой, и при этом не схлопывает строки, как это делает GROUP BY. Поэтому в одном запросе можно видеть и детальную строку, и агрегат по её группе.

Синтаксис: функция() OVER (PARTITION BY ... ORDER BY ... рамка).

## Ранжирование

ROW_NUMBER присваивает строкам уникальные номера по порядку. RANK даёт одинаковый ранг равным значениям и пропускает следующие номера: 1, 1, 3. DENSE_RANK тоже даёт одинаковый ранг равным значениям, но без пропусков: 1, 1, 2.

Типичная задача «последний заказ каждого клиента» решается через ROW_NUMBER() OVER (PARTITION BY client_id ORDER BY created_at DESC) с последующим фильтром по номеру 1.

## Смещения

LAG возвращает значение из предыдущей строки окна, LEAD из следующей. С их помощью считают разницу между соседними событиями, например время между визитами пользователя.

## Накопительные итоги и рамки

SUM(amount) OVER (PARTITION BY client_id ORDER BY created_at) даёт накопительную сумму. Рамка ROWS BETWEEN 6 PRECEDING AND CURRENT ROW превращает агрегат в скользящее окно из семи строк, что удобно для сглаживания дневных метрик.

Если ORDER BY указан, а рамка нет, по умолчанию действует RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW, и строки с одинаковым значением сортировки попадают в окно вместе.
